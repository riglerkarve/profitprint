# Content Site (Bet 1)

Astro static site for the 3D-print-pricing niche. Ranks for how-to/buyer-guide queries, monetized with Amazon affiliate links (buyer guide) and — later, once big enough — AdSense. Cross-promotes the free calculator and the Pro spreadsheet.

## Local dev (needs Node 20+)
```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
```
> Not built locally during scaffolding (no Node on the authoring machine) — CI (`.github/workflows/deploy.yml`) builds and deploys it. The structure follows standard Astro content-collections; review the first CI build.

## Structure
- `src/content/posts/*.md` — articles (frontmatter schema in `src/content/config.ts`).
- `src/pages/` — home, `/guides/`, per-article `/guides/[slug]`, and legal pages (`disclosure`, `privacy`, `about`).
- `src/layouts/Base.astro` — SEO meta, canonical, nav/footer, analytics stub.
- `public/robots.txt` — points at the sitemap (generated by `@astrojs/sitemap`).

## Seed articles (all original)
1. How to Price 3D Prints So You Actually Make Money — pillar.
2. The 7 Costs Every 3D Print Seller Forgets.
3. Best Budget 3D Printers for Starting a Print Business (affiliate buyer guide, disclosure at top).

## Before going live (human checkpoints)
- Read/approve the DRAFT legal pages; add a real contact email (About).
- After Amazon approval, replace `YOUR-ASSOCIATE-TAG` in the buyer guide.
- Add the Cloudflare analytics token in `Base.astro`.
- Set the real deployed URL in `astro.config.mjs` (`site`).

## Monetization & how to check on it
- Google Search Console: indexed pages, impressions, clicks.
- Amazon Associates dashboard: affiliate clicks / conversions (manual export).
- Cloudflare Web Analytics: traffic by page.
